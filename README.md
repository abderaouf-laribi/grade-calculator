# Student Grade Calculator

A simple Python application that calculates the average grade
of a student and determines whether the student passes.

## Features

- Calculate the average grade.
- Determine whether a student passes.
- Classify grades as Excellent, Good, Average, or Fail.

## Installation

Install Python, then install the required dependencies:
python -m pip install -r requirements.txt

## Run Tests
python -m pytest -v

## Run Linting
python -m flake8 .
